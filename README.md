# Business statistics and analysis
This repository contains the following files:
* Excel file conducting hypothesis testing on data from three airlines.
* Excel file with formulas to calculate confidence intervals using sales data.
* Excel file with stock return data and formulas to calculate the confidence interval for the average return.
* Excel file utilizing statistical distributions to address a store problem.
* Excel file applying the normal distribution to an airline and production problem.
* Excel file with formulas to calculate the covariance and correlation between two random samples.
* Excel file with formulas to calculate data descriptors related to customer order information.
